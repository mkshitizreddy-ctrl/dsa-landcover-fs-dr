================================================================================
1. DATA AND PROTOCOL
================================================================================
Dataset: pcap.csv (one row = one network packet; Hash = malware sample)
Rows used: 736,839   (removed 812 rows of Agent and Tsunami: too few hashes for a grouped split)
Families: Benign, DarkNexus, Gafgyt, Generic, Mirai, Unknown
Features: 36   (constant columns removed: SMTP, SSH, IRC)
Development rows: 591,484   Test rows: 145,355   (split grouped by Hash; test set used once)
Grid sample: 22,467 rows (at most 5 per hash), 4-fold CV grouped by Hash
Main metric: macro-F1 (every family counts equally); accuracy also reported.
